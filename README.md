# BlitzFlash iOS

Native iOS version of BlitzFlash, built with SwiftUI.

BlitzFlash is an English vocabulary learning app based on the BBC 800 Essential Word List. This iOS version ports the current web app's core learning modes into native screens:

- Serbest Mod
- Yazarak Tahmin
- Cumle Tamamla
- Kelime Avi

The vocabulary data is generated from the existing BlitzFlash web repository and currently includes 790 words with Turkish meanings and example sentences.

## Development

Open `BlitzFlash.xcodeproj` in Xcode and run the `BlitzFlash` scheme on an iPhone simulator or device.

## Current Status

This is the first native foundation. It includes local vocabulary data and playable first versions of the four learning modes. Persistence, leaderboard storage, refined animations, and App Store assets are planned next.
